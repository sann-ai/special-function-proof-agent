# Upstream provenance

Special Function Proof Agent is an independent MIT-licensed project derived from
[Bessel Proof Agent](https://github.com/sann-ai/bessel-proof-agent), commit
`aae15f00e38981d8ea5d5bf12937498c83edc575`.

The original Bessel Lean library and closed v1 proof recipes are retained. The
Python entry point is `special_function_agent`, the Lake package is
`special-function-proof-agent`, and the default external archive is
`~/SpecialFunctionProofAgentData/archive`.

The upstream project and its personal data directory are separate. Importing an
upstream verification run is an explicit operation that preserves the source
mathematical environment and rechecks the fixed request in this project.

Pinned foundation: Lean `v4.34.0`, mathlib
`db00fb3901b1bb4954f8a2373285959a5930bbfa`.
